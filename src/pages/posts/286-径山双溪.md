**教大家如何享受纯净舒服的推特时间线**
教大家如何享受纯净舒服的推特时间线，不错过你的好友的高质量信息流，给到 Grok Bot 的提示词大概是这样，大伙也可以玩玩，不过这里会消耗原有 X API 的额度，相信聪明的你有办法绕过。

```markdown
每天晚上 8 点，帮我整理今天中文推特圈的精选，来源是我关注的中文账号，加上你觉得不错的中文账号。只用 X 官方 API 读帖子，跟前一天去重。

排版：

- 开头放「今日主线」，3 条短句
- 每个人单独一节，写上名字和 @，节和节之间加分隔线
- 每节 2 到 4 条要点，格式是「加粗主题：内容 + 原帖链接」，每条写两到四句，讲清楚他说了什么、关键细节和背景
- 每节最后用一句话写你的看法
- 零碎工具放到最后的「小工具」一节
- 大约 10 到 15 节，不写破折号，少用句号，不要有 AI 腔，简单清晰就好
```

然后我每天就可以收到这个非常有用的消息了，让我少刷推特，更加专注一点。

**我终于没有忍住，又冲了一个 Claude 250 刀的账号**
我终于没有忍住，又冲了一个 Claude 250 刀的账号，终于够用了，想和大伙聊聊我是物尽其用的如何用完 2 个 Claude Max 账号加一个 ChatGPT Pro 账号的。

我记得从 ChatGPT 3.5 开始以后，玩大模型的一般会有两个流派，一个是坚持使用当前最好的模型的人，一把梭把事情做完，但看着有点“败家”。还有一类是尽可能使用当前性价比最好的模型，通过多模型调研以及工程解法把一般模型发挥出接近好模型的效果，不过这里一般会多花一点时间。

两种用法我感觉都挺好，属于不用工程师性格的选择，我平时时间不太够，加上当时在做业务 AI 落地的时候，会有一个习惯使用当前业界最好的模型去测试效果，这样心里有一个底，知道当前模型高度以及更好的业务判断，等到 25 年初 Claude CLI 出来，体验到了那种厉害模型写代码的效果后，一直就坚持选择当前最好的模型来做自己的事情，然后从 1 个 20 刀试试，到 2 个 20 刀，然后到 1 个 125 刀然后 250 刀的账号，然后到现在 2 个 250 刀账号，属实不敢想，当时 AI 没有出来前，包一个爱奇艺电视会员几十块一个月都会觉得贵的人怎么现在对 AI 这么能花钱，也是神奇。

当前对于 Claude 普通任务我会选择更快的 opus 5.5 medium 档位，复杂任务使用 high，然后对于 Codex 默认用 GPT-6-Astra medium，因为他的其他模型的确不是很好用，不过有一说一 Codex 的 computer use 是真的好用，所以在 Claude 里面我也会通过 lcu 这个工具让他去调用 Codex 的 computer use，效率效果都好不少。

<img src="https://cdn.tw93.fun/blog/2000/pic-IMG_410048.webp" width="800" />

聊起 computer use，以及 AI 操作设备，这一块就非常好玩了，最近开发一些 Window 软件，我买了 Parallels Desktop 这个装到 Mac 上，用 computer use 去操作他非常多的功能，完成代码编写以及 AI 都在 Mac 环境，但是调试验证在这个虚拟机里面，然后考虑到更真实的效果，我去整了一台 ThinkPad X1，也让他 24 小时开机，然后用 UU 远程连接，让我的 Mac 可以使用远程终端以及 ssh 还有 UU 也可以非常好的操作这台真实的 Windows 电脑，帮我去做大量的多环境测试验证、以及各种软件安装、卸载、清理的验收工作。除此之外，我的 Mac 还数据线连接了我的 Android 小平板，通过 Android 调试功能也可以让 AI 非常好的去操作这一台类手机设备，可以帮我打开 App 去查询操作一些没有 API/CLI 的服务，以及操作一些有意思的东西。

这样就好比 Mac 是我的研发主力端，但是他上面连接了一个虚拟机、一台 Windows 设备、以及一台 Android 平台，还有操作 Xcode 自带的 iPhone 模拟器，等到后面想开发 Linux，我甚至可以在 Windows 里面再装一个 Omarchy，那就配齐了，这样有一个好处就是我的 AI 工作上下文只在一台设备，外出的时候通过 UU 远程来操作 Mac 做所有的事情，甚至我感觉 UU 远程在命令行输入的时候不好用，我还自己用 Kaku 做了一个有意思的功能，可以在浏览器上完全镜像操作我 Mac 上的 Kaku，体验很不错，等后续放出给大伙试试。

一方面 AI 操作设备帮我验证各种环境、多维度的测试验证会消耗不少 Token，另外一方面的确开发工作量很大，平时一般是 Kaku 里面 7-10 个 Tab 的 Agent 在跑我的任务，这也是大伙看到我的 GitHub 为啥可以清空所有 issue 的原因了，哈哈哈。

然后平时也会使用 /loop 功能，帮我去做一些收集的事情，比如收集社交平台上大家对于我产品的建议、Bug 反馈，我会让 AI 连接我的 Notion 记录一个列表，收集各种问题建议，详细准备上下文，然后让我的 AI 解决后自动标记完成，以及完成记录。然后就是大家熟悉的 Waza，我基本上每周会用最好的 AI 模型去跑一遍我所有的对话、踩坑、以及最佳实践，然后沉淀到这个开源 Skills 合集里面去，这里也会消耗非常多 Token，不过好处是做了抽象沉淀，让这个东西自己进化起来了。

以及我自己的一些投资、记账记录等等，我会用 AI 自动化帮我去识别、查找、统计各种东西，节约了我的时间，给我做一些信息整理的工作，也非常好用。所以我的账号就是这么被用完了，欢迎小伙伴也说说你是怎么用的。
