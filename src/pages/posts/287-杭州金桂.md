**Mole CLI 开源版本最近更新了非常多的很不错的功能**
<https://github.com/tw93/Mole/>
想着合并到一起告诉大伙，持续迭代，当然非常高兴一转眼已经 72.5K Star 了！

首先首先，Windows 版本的 CLI 经过最近密集的 7 个版本迭代，集中迭代了非常多功能，终于终于和 Mac 版本的使用对齐了，也发布了真正的正式版本，也同步了原有 GUI 版本的绝大部分功能，有 Windows 机器小伙伴甚至直接 scoop install mole 就可以安装使用。

然后然后，终于终于，Mole CLI 有官方的 Skills 了，同时支持 Mac 和 Windows 版本，你可以直接让你的任何 Agent 说 “Install Mole for me by reading https://raw.githubusercontent.com/tw93/Mole/main/llms.txt” 就好了，非常方便，这样你可以和你的 Agent 一起来清理维护你的电脑，包括卸载软件。

再次再次，还有一个有意思的功能，你可以使用 mo slim，可以帮你删除通用 App 里面的 Intel 代码，可以非常直观地进一步帮你删除没有用的东西，非常欢迎试试。

最后最后，Mole CLI 也同步了我当时做 App 时候手工测试的 800 多款 Mac 软件的卸载、清理通用规则，以及 Windows 上 400 多款软件测出来的规则，一并给到大伙使用，因为我一直认为 CLI 和 GUI 只是两个不同形态的产品，虽然 GUI 可以做很多 CLI 做不了的好功能，但是 CLI 胜在简单，可以被 Agent 很好使用，一视同仁会更好，两个会一起持续打磨，做最好用的 Mac 和 Windows 系统维护优化工具！

**最近养成了一个非常好的习惯，我想把它叫做重置**

每次快到晚上，你从外面回来，第一件事其实就是去刷牙洗澡。把自己洗干净，吹干头发，换上干净的衣服，然后再去做自己的事情。

比如说，你 7 点到家，洗完澡 7 点半，到晚上这段时间，都是一段非常新鲜、像重新开始的时间。你的心态、你的心情会完全不一样。特别是对于上班族而言，这个时候下班直接回家立马洗澡，可以洗掉你很多“班味”。

这其实很像大模型里面的 reset 重置。所以我还有一个习惯，就是每天早上起来的第一件事情就是刷牙洗脸，然后泡一杯茶迎接新的一天。

那个时候你的感觉会特别特别好，会非常有新鲜感，就好比“哦，一天终于来了”。这样其实会让你的心情或者身体有一种“我要开始干活了”的仪式感。

非常推荐这个时候不要先刷手机，而是起来以后先把这两件事做了。然后吃完早饭再去干活，或者可以先不吃早饭，先干着活，等到吃早饭的时候再去吃，都没事。

比如说平时你坐得比较久了，也可以站起来走一圈，去接一杯茶、做杯饮料或咖啡，或者去上个厕所、洗个手，诸如此类。这就是给你长时间的专注注意力去重置一下，等到你回来以后，感觉会很好。

放到更长的时间里，家也是一样的。

比如说，每隔 20 天叫几个阿姨过来打扫卫生，把家里收拾得非常干净，就好比给家里也重置了一下。对于不用的东西，及时扔掉或者二手卖掉；包括到换季的时候，把旧衣服进行一次整理，把不要的东西扔掉，或者去买一些更新的，这也是一种很好的重置。

包括经常换被子被套，其实也是一个重置的办法。你会发现，换完被子被套以后，第一次睡上去的感觉是真的很爽。

可能人生也是这样，你得时不时地把你持续很长时间做的事情，或者做得有点疲累的事情尽快重置掉，然后重新开始。就好比洗去尘埃，重新开始做些事情的心态会好太多了。

在一个地方待久了，你可以去远一点的城市找一个好酒店住一晚，或者找个好一点的地方玩一玩、歇一歇，其实这也是换个环境重置一下的办法。

大概就是这个意思，不知道我有没有表达清楚。其实就是尽可能地把自己持续长时间的东西 reset 掉，然后等你重新来的时候，你会觉得有特别新的感觉。

**给关注者比较多的小伙伴一些建议**
假如你以后想做自己的独立产品，那就不太建议你去接商单，一方面这可能是你未来用户不喜欢的点，另一方面会让你感觉还是自媒体来钱快，可能弄独立开发就坚持不下去了。

假如你以后想做更好的自媒体，其实非常辛苦，那非常建议接商单时候认真体验，尽快让用户看到的和你体验的一样，碰到和事实不吻合的单子果断拒绝，或者帮助甲方一起完善后再发。

因为你平时肯定也会持续发好内容，然后夹一些商单，但是只要一次你的商单效果和用户体验差距很大，你的关注者会认为你在骗他，这样后续你发的更多非商单好内容，很多用户也会认为这可能是商单，非常容易先入为主，索性不看了。

因为我们自己既是各种产品的用户，也是关注者，同时还是被关注者。

**几句话把我的 Android 小平板上的系统广告、无用通知、牛皮藓图标都干掉了**

刚刚做了一个非常简单但有用的事情，几句话把我的 Android 小平板上的系统广告、无用通知、牛皮藓图标、以及没有用的预装应用全部干掉了，非常适合当你刚买了 Android 手机、平板，或者是给你的家人来优化手机，现在我的 Android 小平板非常干净了。

首先把 Android 机器使用自带数据线连接 Mac，然后输入我这段优化了的话给到你的 Claude 或者 Codex，然后就等着他去操作就好了。

```txt
请通过电脑连接我的安卓手机或平板，识别品牌、系统版本和已安装应用，帮我做一次减少广告和打扰的优化。

1. 关闭广告和推广
检查系统及应用中能关闭的广告跟踪、个性化广告、内容推荐、热点资讯、营销优惠、福利活动和功能推广，包括负一屏、系统搜索、锁屏、浏览器、应用商店等入口。

2. 保留有用的通知
优先按通知分类关闭推广，保留聊天、邮件、订单物流、支付、账户安全、日历、天气预警、系统更新，以及 AI 回复和任务完成提醒。不要一刀切关闭整个应用的通知，用途不明确的先保留，原本关闭的不要擅自开启。

3. 更换营销图标
把带促销文字、节日或周年装饰的图标换成干净的经典图标，例如淘宝、京东、拼多多、哔哩哔哩。优先使用系统自带的图标设置，OPPO/ColorOS 可以检查「设置 > 桌面、锁屏与个性化 > 图标 > ART+ 图标」。其他品牌先核实支持情况，不盲目安装图标包或更换桌面启动器。

4. 精简系统设置和预装应用
关闭不需要的推广入口和使用体验计划。盘点预装应用，对明确不需要、可安全停用且能够恢复的应用优先停用；卸载前列出名称和影响让我确认。不要仅凭近期没使用就删除，不要动系统桌面、更新、安全、安装器、账户、备份和设备互联等基础服务。

5. 整理桌面
参考近期使用情况，建议哪些应用留在首页或底栏，哪些归入购物、工具、影音等文件夹。先给具体排列方案，确认后再移动。

可以直接执行明确、可恢复的广告和通知设置调整。不要清除应用数据或改动代理、网络设置。每项修改后验证是否生效，最后简要列出已修改、保留和无法处理的项目，不把关闭广告跟踪说成去除了所有广告。
```
