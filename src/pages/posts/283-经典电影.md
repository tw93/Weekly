## 潮流工具

**Window Sweaters：给你的 Mac 窗口织毛衣**
<https://github.com/saragordic/window-sweaters>
给 macOS 窗口套上针织边框的菜单栏小玩具，没什么实用价值，但完成度高，看着好有趣。
<img src="https://cdn.fliggy.com/pic/S9dx0b39.png" width="800"/>

**lazyrsync：Rust 写的 rsync 终端 UI**
<https://github.com/westpoint-io/lazyrsync>
可以保存配置反复使用，同步前用 dry-run 预览文件变化，运行时能看到实时进度，经常同步大目录、又不想每次手搓参数的朋友可以试试看。
<img src="https://cdn.fliggy.com/pic/demo43.gif" width="800" />

**OpenDisplay：开源的 Sidecar / Duet 替代工具**
<https://github.com/peetzweg/opendisplay>
把闲置的 iPhone、iPad 或 Mac 变成 Mac 的第二块屏幕，可以扩展桌面，不只是镜像，iPhone 和 iPad 支持 USB 或 Wi-Fi 连接，也能触控操作，免费开源，有闲置设备的朋友可以试试看。
<img src="https://cdn.fliggy.com/pic/rQHnuy25.png" width="800" />

**Runner：用原生终端编排 Coding Agent**
<https://github.com/yicheng47/runner>
又一个 Coding Agent 终端，让 Claude Code / Codex 等保留各自 TUI，上面加 Role / Crew / Mission，用 Rust + GPUI 社区分支实现，适合并行开一堆 Agent、还想盯着真实终端的朋友，喜欢简单的，还是推荐我的 Kaku。
<img src="https://cdn.fliggy.com/pic/rUKVxj06.png" width="800" />

**Jev：一个专门做快速决策的模型**
<https://typesafe.ai/blog/introducing-system-one-models-and-jev>
这两天在 X 上很火的一个决策模型，不是聊天的那种，而是按预先定义好的结构输出判断结果和概率，官方展示的响应速度很快，调用价格也低，我认为可以放到智能家居、业务分类和判断这些场景里，目前还在早期体验阶段，感兴趣可以去申请试试。
<img src="https://cdn.fliggy.com/pic/66rHkF06.png" width="800" />

**这段时间我在做一件“蠢事情”，可能也是 AI 时代工程师非常不愿意做的那种重复的事。**

为了让 Mole 卸载软件更加彻底，清理残余的能力更强，我整理了国内外 300 多款 Mac 软件，下载下来有 100 多个 G，让我的最强模型开着 Extra High 和 Fast，每批 10 个，借助 computer use 去对应官网下载，然后依次安装到我的电脑，检查目录、检查软件的更新组件、检查自启动、卸载、查找剩余残留、补充缺失的规则。

这个过程看着非常无聊，安装过程中也会碰到不少麻烦的软件，疯狂弹窗要权限，诱导你去购买，有些还必须输入管理员密码才能用，大部分情况 Agent 能自己处理，少部分我帮一手，让我非常惊喜的是，AI 还基于这个过程写了自动化安装、卸载、检查残余的脚本让自己工作更轻松，也是很聪明的，哈哈，我就只能给它打打下手。

虽然无聊，但是对产品功能、对用户用起来爽不爽这件事，其实帮助非常大，当时我想着最多搞 100 个主流软件来测试卸载能力，把没卸载干净的残余补充到 Mole 规则里面去，结果想着要不再搞 100 个，到 200 个的时候，想着再搞 100 个，就到了现在 300 多个了，这或许可以回答 Mole 相比于其他的清理卸载软件的优势是什么，应该就是可以非常细地帮你清理掉很多你找不到的垃圾，卸载得更干净，同时避开那些不该动的东西，这样看就挺有意思的。

经过这个过程，帮我补充了 13 类可以复用的通用规则、90 多条精确的清理路径，也顺手改掉了 30 多个原本以为要清、其实不该动的地方，也补充了不少软件更新检查、自启动检查的规则，甚至还为这些补了 100 多条单元测试。这些细节光靠 AI 已有的理论知识、工程知识很难补齐，得让它实际去做一遍才会碰到，还好有 AI，不然我手工做，估计要花上 10 倍的时间，也帮忙填了一些之前的坑，很有帮助。

也改变了我的一些固有观点，本来以为软件工程应该是规范的、有秩序的，比如说我跑了 100 个软件后，后面应该就没啥可以补充的规则了，因为按理主流软件的开发规范、技术底层完全可以枚举出来，结果越往后走，你会发现，完全不是这样，有很多残余怎么写通用规则都找不着，甚至有些软件的 bundle id 干脆就不是反向域名格式，看着很规范的约定，可能是当年某个程序员随手写的，光靠理论很难推出来，只能装一个查一个。

以后应该会继续做到 400、500、600，甚至把市场上常用的软件全部经过 Mole 来测试一遍，把这些不按规范来的软件留下的细节补进规则，或许正是这些“蠢事情”可以让 Mole 成为全球最好用的 Mac 系统清理优化工具。

**以后决定了，只要电影院上映之前的好电影，我就去看**

周六下午去看了下《肖申克的救赎》，和之前用电脑、电视看的感觉完全不一样，很沉浸，很享受，仿佛体会到了 1994 年人们在电影院看它的那种感觉。

虽然看过几遍，但是进电影院之前，剧情细节已经忘得差不多了，随着电影慢慢回忆起来的感觉真好。小时候看这个电影有一种在外面看里面人的感觉，现在稍微年长后看有一种从里面看外面人的感觉。

往往困住一个人的不是按部就班的学习、工作、房贷、养娃，而是在这个过程中认为自己的人生就这样了，直接认命了，有点儿像老布在监狱图书馆工作了大半辈子，出来后完全不适应，最后留下“老布到此一游”，结束了自己的生命。

真正的监狱往往不是物理的围墙，而是我们心里给自己建的围墙。Fear Can Hold You Prisoner, Hope Can Set You Free. 恐惧让你沦为囚犯，希望让你重获自由。

我在想人不管在什么时候，都要有希望，都要追求自由，终究会有一天也可以到达我们自己所期待的芝华塔尼欧。
